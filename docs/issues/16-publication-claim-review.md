# #16 Review limitations, claims, and reproducibility before publishing

**State:** open  
**Epic:** #9  
**Created:** 2026-05-31

---

## Summary

Review the draft and artifacts before publication to make sure the claims are accurate, reproducible, and safe to share.

## Acceptance Criteria

- Sensitive values and private paths are removed or redacted.
- Claims are checked against trace data and run notes.
- Limitations are explicit.
- Reproduction steps have been run once from a clean checkout or documented equivalent.
- Final publish checklist is included in the article or experiment docs.

## Notes

This step is intentionally separate from drafting. It prevents overclaiming and accidental disclosure.
